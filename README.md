# topdeck-bots

Боты для [TOPDeck.ru](https://topdeck.ru). Каждый бот — отдельная папка со своим README, `.gitignore` и тестами.

| Папка | Что это |
|---|---|
| [`auctions/`](auctions/) | Telegram-бот: персональный watchlist карт MTG и уведомления об окончании аукционов за 1 день / 3 часа / 1 час / 15 минут. Один поллер обслуживает всех пользователей |
| [`cards/`](cards/) | Движок распознавания карт MTG по фото и видео (C++17 + OpenCV + Tesseract): код сета и номер коллекционера из нижнего левого угла, подсчёт карт на видео, отладочный оверлей, C API и Python-биндинг. Основа будущего бота коллекций |
| [`collection/`](collection/) | Telegram-бот коллекций MTG: фото/видео/кружок со стопкой на входе — распознанные печати в личную коллекцию (SQLite), CRUD (`/list`, `/add`, `/sub`, `/del`, кнопки ±/🗑). Переиспользует `topbot` и биндинг `cards/` |
