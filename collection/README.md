# collectbot — сканер коллекции MTG

Telegram-бот: пользователь присылает фото или видео карт (пузырём или файлом),
движок [`cards/`](../cards/) читает строку коллекционера, и распознанные печати
попадают в личную коллекцию в SQLite. Имена карт подтягивает Scryfall
(переиспользуется клиент из [`auctions/topbot`](../auctions/)).

## CRUD

| Операция | Как |
|---|---|
| **create** | прислать фото/видео (пузырь или файл) — каждая распознанная печать +1 копия; `/add TMT:67`, `/add Ninja Teen`, `/add TMT:67 3` |
| **read** | `/list` — по сетам, с количеством копий |
| **update** | кнопки `➖`/`➕` под результатом скана, `/sub TMT:67` |
| **delete** | кнопка `🗑` под результатом скана, `/del TMT:67` |

Каждый показ карты в видео и каждая карточка на фото — одна физическая копия
(стопку листают по карте за показ). Ошибся — `➖` под результатом скана.

## Запуск

```bash
cp .env.example .env       # вписать BOT_TOKEN
./collection.sh            # venv берётся из ../auctions/.venv (COLLECTION_VENV для своего)
```

Тесты: `../auctions/.venv/bin/python -m unittest discover -s tests -t .` из папки
`collection/`. Данные: `data/collection.sqlite3` (в git не попадают).

## Как устроено

```
collectbot/
  config.py    — .env → Settings (общий load_env_file из topbot)
  db.py        — CollectDatabase(topbot.Database): таблицы collection_cards,
                 prints_cache поверх схемы topbot (users/card_names/sets/meta из коробки)
  scanner.py   — ctypes-биндинг cardscan: фото/видео → JSON-отчёт → ScanCard
  resolver.py  — печать «сет:номер» → имя карты: кэш prints_cache, потом Scryfall
                 /cards/collection (батчами ≤75), негативный кэш на 7 дней
  bot.py       — aiogram: команды, медиа-хендлеры, кнопки ±/🗑
```

Шаринг с соседями по репо — сознательно максимальный:

* **интерпретатор и пакеты** — `auctions/.venv` (aiogram, aiohttp уже там);
* **`topbot`** — `Database`/`ensure_user`, `ScryfallClient`, `Card`, `plural`,
  `setup_logging`, `load_env_file`;
* **`cardscan`** — ctypes-биндинг движка `cards/` (пути добавляются в
  `collectbot/__init__.py`, работает из любого cwd).

Пользовательские медиа — временные: файл скачивается в `TemporaryDirectory`
и удаляется сразу после скана, в базе остаются только идентичности.

## Ограничения (базовая версия)

* Распознавание — только OCR строки коллекционера (канал codes): C API движка
  не поддерживает pHash/ORB-индекс, поэтому 1.9 ГБ кэша эталонных картинок боту
  не нужны вовсе. Карта в блистере/с бликом честно уходит в `unknown`.
* Скан видео — минуты на длинный ролик (движок обрабатывает каждый кадр);
* Имена карт — только из кэша/Scryfall; без сети бот показывает `SET:номер`.
